# 衣物处理等待体验 · 2026-10-04

## 已实现

衣物进入处理后自动出现一次居中小提示，直接提供“和鱼搭助手聊聊”“衣物记忆翻牌”“先去逛衣柜”“留在这里看进度”。右上角保留站内任务查询，等待页保留活动入口。关闭提示后，轮询和刷新不会重复弹出；重新提交处理可再次提示。

单件保留原有真实步骤和耗时；多件增加已等待时间、真实结果件数。全局监测复用现有任务与批次 API，按任务 ID 跟踪，批次子任务合并提醒。生图调用结束后仍等待本地衣物任务，失败、未知、取消和需检查分别提示，不自动重试或入柜。

聊天入口打开已有助手并提供三个话题，选择后仅预填，用户发送后才调用模型。保留现有草稿、消息额度和图片授权。手机全屏助手内也能看到完成提示。

翻牌使用本地上衣、裤子、鞋和帽图案，共 8 张、4 对，无倒计时和 AI 调用。显示配对数和翻牌次数，关闭后保留本轮，可以重新开始。任务完成不关闭游戏或聊天，点击“去核对”才进入结果。

- 单件、多件开始提示均可见；关闭后经过轮询和刷新不重复出现。批次生图调用为 SUCCEEDED、子任务为 RUNNING 时仍显示处理中，任务列表仅一条批次记录，没有重复子任务。
- 验证翻牌、不匹配回盖、四对完成、再玩一局、关闭重开保留本轮。完成时游戏内出现结果入口，原页面和翻牌次数保留。

- 修正了详情页轮询持续推迟全局计时器的问题：新任务唤醒闲置监测，详情页重复更新不重新推迟计时器。在批次页面持续刷新期间，另一个单件任务完成仍能被全局监测发现。
