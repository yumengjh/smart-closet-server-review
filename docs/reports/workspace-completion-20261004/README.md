资料、展示图与记录是同一衣物路由内的独立视图。保留业务契约，不强制用户顺序访问每个视图。正常单件录入依然直接提交“识别并整理”；系统完成处理与用户确认入柜继续分开。

## 状态和输入保护

- 所有可见交互使用 Ant Design Vue，原始照片统一进入对照弹层。
- 编辑取消恢复进入视图时的输入；保存冲突合并时也同步取消基准，避免取消后意外回写旧的并发字段。
- 穿着建议核对仍通过用户 overrides 保存，未知不能假装已核对；改变穿着建议会取消本次未提交的核对标记。
- 站内离开未保存编辑时使用 Ant 弹层，保存成功才离开；处理/保存失败继续保留输入。
- 单件页之间切换时重新读取来源信息，避免沿用上一件的批次。继续贴纸和重做保留批次查询上下文。
