# 合图候选、结果管理与比例修复

## 已复现问题

1. 批次只有入柜总数，无逐件状态；试用把已入柜目标也作为候选。
2. 目标刷新与档位变化自动选第一组，成功提交后没有清空，导致旧目标再次被选中。
3. 复选框文本多行但控件顶部对齐，缺少目标局部缩略图及稳定编号。
4. 最新两次返回1774×887（2件）与2172×724（3件），按固定横排格位准确对应，但只按请求1024×1024比例校验，误拒绝有效整理图。

## 修改

- 后端读取每件实时ACTIVE入柜状态并提供confirmed字段；前端可选列表排除这些目标，结果卡明确标注已入柜且隐藏入柜/重做操作。后台提交同时阻止已入柜目标，额度不被占用。历史图的本地恢复不会改动已入柜衣物，也不会用旧调用覆盖新调用。
- 选中目标保持稳定ID，候选与结果沿用原始编号。勾选展示原图目标局部缩略图、本次分组和格位。实际提交按原目标顺序排列；后台调用冻结targetIds，拆分逐格绑定目标、独立工作流及衣物ID。模型是否把目标画在指定格位仍需原图核对。
- 不自动勾选，档位调整保持用户选择；提交成功立即清空并持久化，失败保留选择。刷新、轮询与开关切换保留当前选择，已入柜项自动剔除。
- 拆图接受请求画布比例或冻结网格的正方形格位比例（误差1%）；按真实像素拆分并保留透明通道。任意其他比例仍阻止，避免静默串格。1～3件旧横排与4件起二维布局保持兼容。
