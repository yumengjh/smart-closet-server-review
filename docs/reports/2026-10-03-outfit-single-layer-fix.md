# 保守搭配与拼贴遮挡修复

用户已选择「资料不足就不自动叠穿」。现有衣物资料尚未建立厚度、版型或单品间兼容证据，因此本轮不臆造兼容信息：所有 wearing profile 明确返回 layeringVerified=false，后端 daily-single-layer-v2 拒绝 TOP/ONE_PIECE 与 OUTER 同套自动推荐。自动编辑和预览接受也使用同一规则。手动编辑不受此限制。

提示词同步要求优先生成单层主体，不把品类、季节、门襟或模型理由当作叠穿证明；必须保留的指定单品无法满足时说明限制。已有重复外搭、连衣裙与衬衫冲突、缺少主体等约束继续生效。

拼贴整理改为主体在左、外搭在右，衣物按比例缩放并保持画板边界，避免不透明外套图片覆盖主体。单层方案仍居中；已有画板不会被自动移动，点击「整理穿搭」才应用新布局。

## 边界

这是一项防止无证据叠穿的保守保护，不是具体单品兼容模型。现阶段自动推荐不再包含外搭，可能减少可选方案；也不会自动移除已有搭配中的外套。未来要恢复可靠自动叠穿，应先新增可核对的厚度/版型/兼容元信息，再开放规则。色彩、场景及审美质量没有因这项修复得到全面保证。
