# 多件合图当前设计

[查看设计](index.html)。当前 Figma 文件“鱼搭总设计稿”，页面“衣物工作台 · 当前方案”，页面 ID `7:1248`。桌面主线在 02 区，手机在 04 区；其他分组与弹层在 07 区。主流程和状态共 25 张，本目录只交付这条多件合图流程。

- 选照片 → 识别完成 → 勾选衣物与分组 → 自动合图、拆分、去背景和贴纸 → 整理结果。
- 衣物卡只保留局部缩略图；原图统一通过图片图标查看，不在每张卡重复整张来源照片。
- 合图与逐件入口区分；原来的每组 1 件对应逐件整理，合图设置建议从 2 件起。保留自定义至 10 件能力，按可处理衣物数禁用超出上限的值。本例六件，7–10 禁用。
- 额度按选中件数 / 每组件数向上取整。4 件每组 4 件是 1 次；每组 2 件或 3 件是 2 次。分组中的末组可不足设定件数。
- 原站侧栏、主题、声音、助手和手机导航使用原有图层，辅助说明用图标弹层。
- 贴纸制作是自动处理阶段；单件恢复属于暂停或失败的例外。没有添加单件录入必须逐页核对的流程。
