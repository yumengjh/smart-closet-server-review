# 蓝色 Bloub 助手悬浮球

确认日期：2026-10-02。状态：已实现，2026-10-02 完成验收。

## 形象与集成

- 默认圆形 `cercle`、蓝色 `bleu`（#3b93f0），动作可短暂形变，结束回圆球。
- 本地复用 [bloub](https://github.com/jeremy-prt/bloub) SVG 引擎，固定版本 `b4bb3c1b5f93c7b87a2e8d620f667c4093d97749`，保留 MIT 许可，不引入演示界面、Tailwind 或视频导出依赖。
- 悬浮球播放完整动作；面板标题和空聊天欢迎区使用同一角色，但保持静态或轻微表情。
- 保留 Ant Design Vue 控件、右侧覆盖面板、键盘操作、拖拽位置记忆、LatticeLoader、ThoughtLine 与搭台 Aurora。

## 动画分配

| 动画 | 使用场景 |
| --- | --- |
| idle | 待机圆球、眨眼 |
| thinking | 真实思考、三点脉动 |
| comet | 查询衣柜、检索帮助；空闲玩法 |
| orbit | 操作搭台；空闲玩法 |
| notify | 结果准备好、等待确认 |
| alert | 实际失败，配合错误文字 |
| wink、wide | 友好、认可、好奇、惊讶；空闲玩法 |
| exclaim | 对话强调、惊讶 |
| sleep、egg、hexagon、play | 空闲玩法或合适的聊天表达 |
| burst | 真实成功、感谢表达或空闲玩法；不附带虚构成功信息 |
| swirl | 唤起过渡，目录外、本地控制 |

流式回复默认专注圆球加轻微呼吸。全14公开动画均接入预览和实际使用场景，不强制每轮表演。

## 混合控制

- 真实阶段由 SSE 状态、工具名、画布执行结果决定；拖拽由本地指针事件决定。
- Agent 可见14动画名称和短用途，以及中性、专注、开心、好奇、惊讶、困惑、羞怯、关切表情，不可控制坐标、SVG、颜色、曲线、时长或逐帧代码。
- 每轮最多一次有效自主表达。思考、错误、工作、待确认动画必须符合真实状态，错误选择忽略。
- 个性档在现有回复开头附带可选短元数据；Runtime剥离并发送独立 `avatar` SSE。无需动画专用模型调用、工具循环或回调。
- 后端白名单校验并附当前请求ID，前端只接收当前请求。不存历史、不重播旧动作。元数据缺失、非法或解析失败均不影响正文。
- 个性档增加提示及输出token，现有用量统计涵盖它；工具循环会重复计入输入提示成本。基础/静态档不加入动画提示。

## 空闲与拖拽

- 待机时目光平滑跟随页面内鼠标，不限于靠近小球；离开窗口或切到后台时回正。触屏不追踪悬停，任务与趣味动作保留各自原有目光。

- 收起、无任务时随机隔10–20秒短播一个动作，连续不重复，之后回圆球。
- 空闲池：wink、wide、sleep、egg、hexagon、play、orbit、burst、comet。thinking/alert/notify/exclaim不随机触发。
- 鼠标靠近、拖拽、展开、页面后台时暂停。恢复不补播；新任务/错误即时打断趣味动作。
- 按下轻压缩，拖动沿方向轻拉伸并跟随目光，松手柔和恢复；停在松手位置、不吸边、限制屏幕内。位置按账号及设备保存。

## 设置与接口

- `/api/agent/preferences` 增加 `avatarMode: static | basic | personal`，账号持久化，默认personal；模型与动效可独立更新，兼容旧客户端。
- static：关闭持续动画、随机、拖拽形变及自主表达，状态仍有文字。
- basic：任务、交互与空闲动作，不加入模型表达提示。
- personal：基础能力加每轮最多一次自主表达。
- 系统减少动态效果优先；角色不可见或页面后台时停止动画调度。
- 设置提供全部动画与“思考→操作→回复→完成”独立预览，不请求模型，不改变真实任务。
- 音效沿用已有服务与总开关；全部控件使用Ant Design Vue。
- 修改前端源码后使用 `npm run build:server` 发布，禁止手改压缩产物。

## 验收

- 全14动画和swirl可预览；任务、错误、确认与成功状态准确。
- 元数据跨分片、遗漏、非法、重复、旧请求不破坏正文或泄漏控制信息。
- 三档持久化；基础/静态无额外动画提示；模型请求次数不增加。
- 空闲间隔、不重复、后台停止与减少动态效果正确。
- 桌面/手机拖拽跟手、防误点击、边界、位置记忆、键盘操作。
- 面板不挤压主布局，现有音效开关、搭台特效与聊天功能保留。

## 实施与验收记录

- 前端引擎在 `src/agent/bloub/`，本平台渲染器 `BloubAvatar.vue` 不使用上游演示轮播；统一蓝色圆球，保留平滑形变。
- V8迁移持久化动效模式；旧客户端只更新model时保留avatarMode，按账号隔离。
- Runtime使用有界的回复前缀解析器，处理分片、非法JSON、缺省表情和未闭合控制行；有效表达独立传输、不保存。
- Runtime 11项测试通过；后端AgentApiTest 7项通过；前端类型检查及发布构建通过。
- 浏览器隔离QA（模拟上游）验证15种预览、三档切换和刷新持久化、拖拽拉伸与位置记忆、thinking→comet→thinking→回复→wink及正文无控制信息、390px手机无横向溢出/不挤压主布局、系统减少动态效果及恢复、空闲随机egg后回idle、完整任务流程预览。
- 前端完整测试32项中31项通过；衣物初始摆放测试 `new garments receive deterministic category positions without mutating earlier items` 失败，在未修改HEAD的独立副本中同样复现。本次不改动该布局算法。
- 个性表达不强制出现，真实模型可能选择不输出元数据；不得为补动画重试模型。预览与基础动作可随时观察，无需消耗模型额度。
