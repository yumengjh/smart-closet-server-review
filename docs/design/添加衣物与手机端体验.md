# 添加衣物与手机端体验

确认日期：2026-10-02。面向在手机及桌面使用鱼搭的普通用户。

## 目标与边界

一次录入一件衣物，支持平铺、悬挂、自拍及镜子照。自拍由系统自动选择画面中突出、居中且可辨的主视衣物；不能确定唯一目标时要求补拍，不强行猜测。不做整套批量拆分，不新增本地模型或个人偏好记忆。

图片、衣物信息和是否入柜分别表达。原图始终保留，模型结果只有经过用户核对才入柜。自拍中不可见、被遮挡的结构不能保证还原。

## 页面与配置

- 桌面保持左侧照片、右侧处理方式；手机按选照片、选处理方式、提交的顺序排列。
- 可见按钮、上传入口、模式选择、开关、展开区域和弹层均使用 Ant Design Vue。隐藏文件输入、视频与画布作为底层机制保留。
- 三种方式为“帮我识别并整理”“只帮我填写信息”“本地去背景，自己填写”。常驻说明各自适用照片、输出结果和额度；详细说明可点击查看，不能只依赖悬停。
- 高级配置默认收起，仍可选择模型及改变处理开关。默认整理开启、预抠图关闭、透明贴纸开启。
- 用具体、温和的文案表达状态，例如“拍得清楚就很好，不必像商品图一样完美”“照片已保存，可以先去做别的，回来再核对”。不能用鼓励文案代替错误原因。
- 触控目标至少 44px，兼容深浅主题、键盘、可见焦点及减少动态效果偏好。页面无横向溢出，提交按钮不能被底部导航或助手遮挡。
- 模型/额度读取失败只阻断相应 AI 操作，不阻断本地处理。

## 摄像头

页面进入后静默检测可用的视频输入设备，不主动申请权限。有可用设备时显示拍照入口；没有设备、浏览器不支持或检测失败时隐藏，始终保留相册入口。设备变化时重新检测。检测失败不等同于硬件不存在。

手机通过系统拍照入口提示后置拍衣物、前置自拍；系统是否遵循 capture 由浏览器决定。桌面在用户点击后请求摄像头权限，通过 Ant Design Vue 弹层预览、拍摄和重拍。关闭弹层或离开页面释放摄像头。拒绝权限、设备被占用、取消拍照时保留已选照片并引导相册上传。

摄像头检测及桌面预览通常要求 HTTPS 或 localhost。普通局域网 HTTP 的能力不足时仍可从相册选择照片，不因此阻断录入。

## 自拍识别与整理

识别的新版本输出主视目标描述、归一化位置及是否为穿着照；元信息仅属于该目标。无目标、目标不明确或严重模糊时沿用现有阻断状态。有遮挡时提取可见字段并提示核对。

识别完成后，服务端使用同一个目标补充图片整理预设。去除人物、其他衣物、配饰和背景，保留目标真实款式、颜色、文字、纽扣、口袋及结构；不要求凭空还原隐藏细节。模型输出的目标描述作为数据表达，不作为可执行指令。普通用户仍不能提交任意图片整理提示词。

穿着照跳过前置本地抠图，使图片模型看到完整照片。目标在结果页明确展示。重新整理仍从原图出发，沿用已有目标；没有目标的旧任务使用预设主视规则。旧识别结果继续可读，新结果版本与历史版本分别记录。

## 本地去背景问题及修复

已核对历史任务 `520c8ab6-680a-40c0-9ab7-099a38104813`、`13346629-1fb9-46ff-bdd8-46e099fa2285`：输入只有圆角透明，内部仍包含地面、墙面、白底或其他物体；Alpha 检查却返回 USABLE，随后以 REUSED_ALPHA 跳过分割。这证明透明像素检查不能证明衣物背景已经去除。

新添加页本地模式默认发送 FORCE，强制执行一次 U²-Net 分割，再检查结果并制作贴纸。高级配置提供“背景已经透明，直接制作贴纸”，仅用户主动启用时使用 AUTO 复用。上传参数新增可选透明策略；旧客户端缺省 AUTO，不改变既有调用。

结果检查不通过时保留中间图并给出继续操作。即使贴纸已完成，也提供“背景还在？重新去背景”，使用抠图前的源图片执行本地处理，不重新生图、不使用 AI 额度。操作遵守原有任务活动状态、账号归属及幂等约束，不自动覆盖入柜展示图。

本地模型是前景分割，不能可靠区分人体与穿着衣物。页面明确提示自拍推荐使用识别并整理；本地模式适合单件平铺或悬挂照片。

## 验证与发布

1. 复测上述圆角透明图片，确认执行真实分割，并目视核对内部背景和衣物边缘；另测透明衣物直接复用、普通 JPEG 和失败恢复。
2. 验证自拍、镜子照、平铺、明确主视衣物、多个同样突出目标及遮挡输入；识别与生成必须是同一目标。
3. 覆盖设备有无、检测失败、拒绝权限、取消拍照及摄像头释放；手机与桌面验证布局、触控、键盘和深浅主题。
4. 验证模型读取失败不影响本地处理，本地处理不调用云端，旧客户端和历史任务仍兼容。
5. 前后端针对性测试、构建和真实图片核对通过后，通过前端 npm run build:server 发布至后端 static；不得手工改压缩产物。核对实际运行页面与接口。
