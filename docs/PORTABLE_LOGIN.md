# 便携登录链接

## 用户体验

设置页的「便携登录链接」要求重新输入当前密码。完整 URL 只在生成后的当前页面显示，可复制给可信设备。链接固定 10 分钟有效、单次兑换；每账号最多有 5 个未使用链接。设置页可撤销未使用链接，也可撤回已经兑换的登录授权。

链接形如 `https://鱼搭站点/wardrobe#portable-login=<随机票据>`。应用启动后立即从地址栏删除 fragment，再通过 HTTPS POST 兑换 Spring Session。链接登录保留签发账号的业务权限，包括衣物、搭配、Agent 和原有管理员业务权限，但不能修改密码或管理登录授权。设置页隐藏对应入口，服务端也强制限制。

链接会话的绝对有效期和空闲时限均为 24 小时。退出、撤销授权、改密、管理员重置密码或停用账号后，授权失效。撤销从后续请求起生效，不会自动取消已经发出的后台任务或持续连接。

## 安全边界

- URL 不包含用户名或密码。票据为 256 位密码学随机值；数据库只保存 SHA-256 哈希，明文只随签发响应返回。
- fragment 不属于 HTTP request target，正常情况下不会进入服务端访问日志和 Referer；但浏览器、扩展、剪贴板和屏幕共享仍能看到它。持有链接即可在有效期内登录，只能私下分享给可信任的人。会执行页面 JavaScript 的链接预览器也可能提前消费票据。
- 兑换使用条件更新原子地标记已消费；重复打开、过期、已撤销都会失败。接收端清除 fragment 后才提交票据，并显式以无 hash 路由完成导航，避免路由重新写回地址栏。
- 登录成功会销毁旧会话并创建新会话，避免会话固定和旧账号状态残留。之后每次请求均检查链接授权是否仍有效。
- 创建需要已有密码登录会话且再次验证密码；初始密码未修改的账号不能签发。签发、查看、撤销及兑换接口保留 CSRF 校验。链接登录不能再签发授权，不能修改密码。
- 远程访问必须使用 HTTPS；仅连接来源和请求主机均为本机回环地址的开发环境允许 HTTP。前端及服务端均校验。生产反向代理必须正确传递 HTTPS 协议，并仅信任受控代理的转发头；不要把开放网络请求伪装成本机开发请求。
- 每次创建时清理超过 7 天的历史票据，查询展示每账号最近 20 条记录。密码修改、重置和账号停用会撤销该账号全部便携授权；普通密码登录会话仍沿用已有生命周期。

此功能用于账号持有者授权另一台可信设备临时操作账号。业务权限包含数据修改和 Agent 额度消耗。公开展示衣物、搭配时应另做不登录、只读且可撤销的分享页。
