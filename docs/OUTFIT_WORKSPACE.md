# 多画板组合台与 Agent 临时搭台

## 产品约定

普通组合台和 Agent 临时搭台共用编辑器。一块有限的 1080×1350（4:5）画板是一套独立搭配，工作区支持缩放、平移、总览和聚焦，最多十二块画板。每板独立名称、场景、选择、撤销重做、缩放、保存标记和搭配版本。未保存工作区按账号在本机恢复，不同步到其他设备；正式搭配仍使用原来的账号保存接口。

每个聊天会话复用一个临时搭台。默认三套，允许一至五套不同方案；库存和容量不足时说明原因。「再来几套」增加画板，「调整这套」只修改当前目标。普通搭配先复制当前未保存状态，临时搭配继续调整。满意后单套保存或勾选多套保存，调整副本可明确选择另存或覆盖原搭配。

## 对齐规则

原先 TOP 与 BOTTOM 默认中心分别是 425 与 555，纵坐标也不按图片高度联动。现在新增布局引擎共用 x=540 中轴，基于透明裁边后的原始高宽比等比缩放，上下装衣摆与下装顶部小幅重叠，并把主穿搭组适配到画板内。外套按层级覆盖上装，鞋在下装下方，包与配饰侧放；连体服单独处理。图片不自动变形、挖空，也不增加模型看图调用。

旧搭配不自动重排；「整理穿搭」才主动重算布局，并可撤销。没有透明贴图时展示现有图片并提示衔接限制，不自动发起收费处理。这是贴纸式近似穿搭，不是真实人体试衣。

## 执行链路

Agent 通过 build_outfits / edit_workspace 提供衣物选择和语义意图，Java 验证真实 ACTIVE 衣物与账号归属，再逐板发出命令。浏览器加载贴图、实际改变场景并回执。Java 在收到版本与场景有效的回执后才记录成功，随后才执行下一条。

命令包括 open、create、begin、add、replace、remove、layout、adjust、finish、complete。adjust 支持左右/上下微移、等比放大缩小和翻转；模型不自由猜坐标。每板一次执行作为一个撤销组，停止后的部分内容同样可撤销。

SSE canvas_operation 包含 runId、sessionId、workspaceId、boardId、operationId、sequence、expectedVersion、kind、label、payload。前端 POST /api/agent/runs/{runId}/ack，回传 operationId、sequence、success、version、scene；open 还回传 boardCount。失败回传简短 message。运行授权只在本轮存活，默认每步最长等待三十秒，整个运行仍受 Agent 超时限制。

回执验证登录账号、授权有效期、命令顺序、画板内容版本、衣物/贴图归属与现有 scene 验证规则；重复事件不重复应用，取消后迟到回执拒绝。临时 boardId 与已保存 outfitId 始终分开。Node 不直接连接数据库，执行过程不调用搭配保存接口。

Spring 7.0.6 起 ServletServerHttpResponse 的 body.flush 默认不刷新到网络，消息控制器显式使用 HttpServletResponse.flushBuffer，避免命令被缓冲到回执超时。代理同样必须关闭 SSE buffering。

## 接管与反馈

逐板执行时，只锁定当前画板；其他画板可编辑。五秒周期的蓝紫极光包围整个搭台操作区四周，边缘有明确蓝色亮带，内层光晕缓慢改变范围与亮度，中心保持清楚；总览里当前画板同时单独高亮。停止按钮始终在蒙层外。减少动态效果时使用静态辉光，音效沿用现有开关。顶部「更多 → 预览 AI 光晕」显示十秒明确标注的效果预览，不调用模型、不改变画板。

默认镜头跟随；用户手动移动镜头或选择其他画板后停止跟随，可主动恢复。「停止并接手」取消剩余操作并保留部分结果。关闭聊天面板不停止操作，离开搭台、刷新、登录失效或执行流中断则停止；恢复草稿不会自动继续执行。

operation_result 记录实际操作成功/失败，workspace_result 提供搭台结果与入口；聊天用紧凑卡片和可展开记录。跨设备没有对应本机草稿时明确提示，不从聊天假装恢复场景。

## 保存与兼容

单套与多套均需明确确认。多套逐条保存，标记成功项及失败项，失败后仅重试失败画板。成功后记录 outfitId、revision 与内容签名，防止重复创建。覆盖仍使用 OUTFIT_VERSION_CONFLICT 并保留本机草稿。

原 /outfits 为搭配库，/outfits/new 和 /outfits/{id} 打开普通多画板工作区；/outfits/workspace?session={id} 打开会话临时搭台。原 scene v1/v2、衣物/人物贴纸、裁切、图层、PNG 导出保留，旧单板本机草稿首次打开时迁入工作区。无需数据库迁移。

## 检查记录

本轮采用类型检查、前后端生产构建、隔离模型的接口与真实浏览器检查，不调用收费上游。实际检查情况见 [验收记录](../reports/outfit-workspace/README.md)，流程用模拟模型内容，不能作为真实模型搭配审美质量证明。

## 搭台工具区重设计（2026-10-02）

工作区顶部只有一条 56px 顶栏，当前名称、画板入口、总览、更多与保存集中在这里。画板管理改为按需打开的抽屉，提供全选、批量保存和批量丢弃；Agent 会话另有「丢弃整个临时搭台」入口，清除该会话本机工作区并返回搭配库，已保存到搭配库的数据保留。Agent 执行期间禁止整台丢弃，所选丢弃会跳过正在锁定的画板；嵌入编辑器不再重复显示名称与保存栏。搭配理由、素材限制、另存／覆盖与音效在更多中查看。执行状态条、存储提醒与画板错误悬浮覆盖，不参与主布局高度计算。编辑器的撤销、面板与缩放工具条保留，手机底部贴纸工具继续避开助手球。
