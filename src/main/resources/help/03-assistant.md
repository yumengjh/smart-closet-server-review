# 个人助手、模型与记忆

## 助手能做什么

助手可查询平台事实、衣柜数量与季节分布、已保存搭配、当前组合台和任务状态，处理明确授权的修改，并回答普通问题。数量查询和“你好”不会自行触发搭配、记忆维护或图片任务。页面与选中项随消息提供，目标不明确时先核对。

单件明确的小修改会显示变化与撤销；回收、批量、覆盖、敏感记忆和图像生成需要具体确认卡。确认绑定对象、参数和版本，十分钟后过期；对象更新后不能用旧确认或撤销覆盖新内容。识别、增强、人物和 OOTD 只有明确要求且确认后才提交，统计与穿搭检查不调用识图或生图。通用联网与实时天气尚未接入，不能核实的外部最新信息会说明限制。

平台问答以帮助文档为依据，未检索到可靠资料时会明确说“暂时不知道”。如果回答未解决问题，可以向平台反馈；当前版本尚无反馈收集入口，助手不会声称已提交反馈。

## 打开与关闭助手

点右下角的小助手表情球打开对话。表情球可拖动，位置会在本机记住。桌面面板覆盖主界面，不挤压组合台；图钉按钮可固定到右侧，取消固定后拖动顶部移动。右上角关闭按钮随时收起，聊天仍保留。

输入区的齿轮按钮打开“对话选项”，可选择本会话模型、授权本条发送当前衣物图片。敏感记忆通过具体内容确认卡保存。角色动效和预览在“我的”设置中管理。授权发送消息后重置。音量按钮沿用平台音效开关，记住本机选择。

想找某件衣服可以直接描述，例如「帮我找那件小熊卫衣」「适合海边的白色上衣」：颜色和品类按资料精确筛选，描述按本机语义匹配，没有就会直说没有并告诉你最接近的一件；命中多件时助手会列出来请你确认。搭配请求先在聊天展示带评分和依据的推荐卡片；点击「在搭台打开」才进入当前聊天的临时搭台，逐板添加真实衣物并排版。也可明确要求直接放到画板。不满意时直接说「重新搭配」「换一批」「再推荐」，会沿用上轮条件；新提出的条件优先，衣柜不足时会说明部分衣物重复。正在操作的画板有极光和进度，可停止并接手；关闭聊天面板不会停止，离开搭台则停止并保留草稿。聊天以紧凑结果卡、搭台入口和可展开实际操作记录展示。满意后由你单套或勾选多套保存到账号。传统预览建议及历史卡片仍可打开大模态框查看。

## 蓝色小助手与动作预览

待机时小球会看向鼠标，离开窗口后目光回正。小助手是蓝色圆球，动作时会短暂变形，结束后恢复。思考、检索、操作搭台和回复跟随真实任务；聊天中助手可以每轮最多选择一次合适表达。拖拽时轻轻拉伸，松手停在当前位置，不自动吸边。

在“我的” /settings 的“角色动效”选择静态、基础动效或Agent个性动效，默认个性，设置随账号保存。基础动作、拖拽及空闲玩法不消耗模型token；个性档在原回复中附带短控制信息，会增加提示及输出token，但不额外调用模型。系统减少动态效果优先。

助手收起且没有任务时，每隔10–20秒随机玩一个短动作；鼠标靠近、拖拽、展开或页面后台时暂停。“动作预览”可以查看全部14个动作和唤起过渡，或播放完整任务流程，不调用模型、不修改实际任务。如果只是想看效果，使用预览即可。

## 模型设置

在“我的” /settings 选择个人默认模型。对话面板可设置当前会话模型或使用个人默认。只可选择后端开放的模型，不可在网页输入上游地址或 API Key。系统默认 gpt-6-luna，使用服务端配置的上游。

## 会话和长期记忆

会话在账号内保存，可以新建、重命名、删除或清空历史。长期记忆在设置中以通用、敏感两份原始 Markdown 文档管理。删除聊天不会删除记忆；临时要求不转为长期偏好。通用局部维护展示变化并可撤销；敏感内容保存先确认，读取另按个性化搭配、基准人物或 OOTD 用途授权。数量查询与普通闲聊不读取身体资料。修改敏感文档后需重新授权；忘记会隔离旧模型上下文，但无法撤回已经发给上游的内容。

个人资料在“我的 → 个人资料与基准人物”管理。男或女必须选择才能生成人物，其他资料可选；男默认170 cm、女160 cm、标准身材，缺体重按 BMI 22 计算示意值，默认值不写回真实资料。可用照片或模板生成单张候选，核对后确认默认人物。资料变化不会自动生图。原照、人物和 OOTD 分别删除；私人图片仅本人访问。

## 额度

助手每天默认可提交 30 条消息，按北京时间重置。每条提交计一次，内部工具调用不另计；上游调用失败也属于已提交消息；同一个请求 ID 不会重复计数，主动发送一条新消息会再次计数。识图、图片整理、基准人物和 OOTD 共享每天 20 个图像额度，本地贴纸不计入 AI 任务额度。额度可以由后端配置。


## 手机使用

手机和平板窄屏打开助手时使用全屏对话，背景页面暂停滚动和操作，只有聊天记录可滚动；关闭后回到原来的页面位置。打开时不会自动弹出键盘，点输入框后再开始输入，输入区会随键盘调整高度并留出底部安全区。
