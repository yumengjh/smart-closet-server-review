# 个人助手、模型与记忆

## 助手能做什么

助手可回答本平台的使用问题、带用户去平台页面、查询自己的已入柜衣物和搭配、生成候选或修改当前组合台。页面与当前选中项会随消息一起提供，面板会显示当前上下文。助手不会任意访问其他账号，也不会启动识图或图片生成任务。

平台问答以帮助文档为依据，未检索到可靠资料时会明确说“暂时不知道”。如果回答未解决问题，可以向平台反馈；当前版本尚无反馈收集入口，助手不会声称已提交反馈。

## 打开与关闭助手

点右下角的小助手表情球打开对话。表情球可拖动，位置会在本机记住。桌面面板覆盖主界面，不挤压组合台；图钉按钮可固定到右侧，取消固定后拖动顶部移动。右上角关闭按钮随时收起，聊天仍保留。

输入区的齿轮按钮打开“对话选项”，可选择本会话模型、授权发送当前衣物图片、同意本条保存个人信息或切换表情。授权发送消息后重置。音量按钮沿用平台音效开关，记住本机选择。

搭配请求会打开当前聊天的临时搭台，逐板添加真实衣物并排版。正在操作的画板有极光和进度，可停止并接手；关闭聊天面板不会停止，离开搭台则停止并保留草稿。聊天以紧凑结果卡、搭台入口和可展开实际操作记录展示。满意后由你单套或勾选多套保存到账号。传统预览建议及历史卡片仍可打开大模态框查看。

## 模型设置

在“我的” /settings 选择个人默认模型。对话面板可设置当前会话模型或使用个人默认。只可选择后端开放的模型，不可在网页输入上游地址或 API Key。系统默认 gpt-6-luna，使用服务端配置的上游。

## 会话和长期记忆

会话在账号内保存，可以新建、重命名、删除或清空历史。长期记忆独立管理：删除聊天不会删除记忆。明确表达的风格、颜色、场景等偏好可自动保存，会提示用户并提供撤销；尺码、身材等个人属性需要明确同意保存。可以在“我的”查看、编辑或删除记忆。

## 额度

助手每天默认可提交 30 条消息，按北京时间重置。每条提交计一次，内部工具调用不另计；上游调用失败也属于已提交消息；同一个请求 ID 不会重复计数，主动发送一条新消息会再次计数。识图和图片整理另有每天 20 次图像任务额度，本地贴纸不计入 AI 任务额度。额度可以由后端配置。
