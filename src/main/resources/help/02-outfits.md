# 组合台与智能搭配

## 创建和编辑

组合台 /outfits 显示账号保存的搭配。点击“新建搭配”，从已入柜衣物中选贴纸，也可加入人物贴纸。在画布中调整位置、大小、角度和层级；可选择多张贴纸进行调整。使用工具栏撤销、重做和整理排版。

未保存修改会自动保留在本机浏览器，尚未同步到其他设备。点击“保存搭配”才保存至账号。导出 PNG 图片会将当前画布输出为图片。

## 助手搭配

打开全局助手，说出场景、风格或必选衣物，例如“用选中这件衬衫搭三套通勤装”。默认从自己的已入柜衣物给出三套不同方案及理由。默认只使用结构化元信息，图片分析需明确同意发送当前衣物图片到模型服务商。

助手方案先展示预览。点击确认应用后才进入当前画布或新建草稿；保存到账号仍需再次确认。生成的新草稿有独立本机草稿，不覆盖原来的新建草稿。当前画布改变后，旧的编辑建议需要重新生成。

## 保存冲突

另一台设备更新了同一搭配时，保存会提示版本冲突。可以重新加载最新搭配或另存副本；不要覆盖未确认的修改。
