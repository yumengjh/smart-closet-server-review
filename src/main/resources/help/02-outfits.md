# 多画板组合台与智能搭配

组合台顶部的规则推荐、今日灵感、换一件、穿着打卡与偏好设置，见《今天穿什么、今日灵感、换一件与穿搭画像》。

## 创建和编辑

组合台 /outfits 显示账号保存的搭配。点击「新建搭配」或「打开多画板工作区」进入工作区。一块画板对应一套搭配，每个工作区最多十二块，可新建画板或打开已有搭配，缩放和平移整个工作平面。总览用于并排比较，聚焦用于编辑当前画板；手机默认聚焦。

从已入柜衣物或人物素材中选贴纸，可调整位置、大小、角度、裁切、翻转和层级，也支持多选。每块画板的选择、撤销重做和保存状态独立。「整理穿搭」按照共同中轴与贴图比例整理上下装、鞋和外套，可撤销。旧搭配不会自动重排，带背景原图可能影响穿搭衔接；这是贴纸式近似排列，不是真实试衣。

## 草稿与保存

工作区及未保存修改按账号自动保留在本机浏览器，不同步其他设备。刷新恢复内容，正在执行的 Agent 操作不会自动恢复。存储空间不足会提示，请及时保存到账号。

顶部可直接修改当前搭配名称、保存或切换总览。点击画板图标打开画板抽屉，切换画板或勾选几块后保存所选。新建、打开已有搭配、导出、另存副本、覆盖原搭配和音效位于顶部「更多」；搭配说明与带背景素材提示也从这里查看。每块独立进入搭配库，成功项有保存标记；部分失败时保留草稿并仅重试失败项。关闭未保存画板会明确提示丢弃。PNG 导出只输出当前搭配，不包含极光、工具栏或工作区背景。

## 助手临时搭台

打开全局助手，说出场景、风格或必选衣物，例如「用选中这件衬衫搭三套通勤装」。默认三套，可指定一至五套；只使用自己的真实已入柜衣物。聊天推荐先展示带评分、亮点与依据的推荐卡片，点击「在搭台打开」后进入当前会话独立的本机临时搭台，逐板添加真实衣物并整理排版；明确要求直接放到画板时也可直接打开。不满意可在聊天里说「重新搭配」「换一批」或「再推荐」，继续上一轮条件，也可补充新的场景、温度或不要的衣物。衣柜不足时会说明部分衣物与上一轮重复。

当前操作画板显示蓝紫极光和步骤提示，并暂时锁定；其他画板仍可编辑。可以「停止并接手」，保留已完成内容后手动调整。默认镜头跟随，手动移动镜头或选择其他画板后停止跟随，可点击恢复。减少动态效果设置会关闭极光呼吸，音效尊重平台开关。四周蓝紫光晕覆盖整个搭台操作区，中间保持清楚。可在顶部「更多 → 预览 AI 光晕」查看十秒效果预览；预览不会调用模型，也不会修改画板。

关闭助手聊天面板不影响搭台操作；离开搭台、刷新或连接中断则停止。对话里保留可展开操作记录和搭台链接，跨设备没有临时草稿时需要在原设备查看或重新生成。

## 调整已有搭配

让助手调整普通画板时，先复制其当前未保存内容到临时搭台，原画板保留。临时画板的后续调整会直接继续编辑它。满意后默认另存新搭配，或明确点击「覆盖原搭配」。运行不自动保存到账号。

默认仅用结构化元信息；图片只有勾选本条图片授权才发送给模型。没有透明贴图时使用现有图片并提示，不自动启动收费图片任务。

## 保存冲突

另一台设备更新同一搭配时，覆盖会提示版本冲突，保留当前草稿。可以通过「另存副本」保存新搭配，或关闭旧画板后重新打开最新搭配；关闭前请先保留尚未保存的内容。不要丢弃尚未保存的修改。

## 全身穿搭检查与 OOTD

组合台的“穿搭检查”使用现有衣物资料和本次穿法免费分析全身分布，不识图。自由画板可摆多套或多人物；生成前只选择一名已确认基准人物和一套物品。复制贴纸只穿一次。日常使用上装加下装，或连体主体；可选一件外搭。明确多层需已核对的相邻版型、厚薄与用途；双外套始终禁止。首饰要有明确不同佩戴位置。

缺主体、位置冲突、角色未确认、衣物回收或无实物参考会阻止 OOTD。缺鞋提示后可继续，结果赤脚，不保留基准人物原鞋；帽子和普通配饰缺少不阻止。不使用基础人物服饰补齐搭配。

先保存搭配，再进入 /ootd；未保存修改不能悄悄改用旧版。选择已确认人物和已验证模型，核对清单及额度后生成单张。当前未验证用途保持关闭，不自动补图、换模型或重生。照片只用于人物建立，OOTD 直接参考已确认人物及真实衣物。结果随账号保留到用户永久删除，不进回收站，不覆盖组合台或加入衣柜。来源后来改变或删除时，已完成结果可以独立保留。反馈不会触发生图，视觉预览不能保证真实尺码、合身或花纹完全一致。
